1. How does the optimal policy change when transition uncertainty increases?
As success probability decreases, the expected value of actions near the trap is reduced because unintended perpendicular moves become more likely. The optimal policy therefore avoids risky cells more often and can prefer longer but safer routes.

3. Why does the agent become more risk-averse near the trap?
Bellman optimality uses an expectation over every possible next state. Near the trap, a slip can produce reward -1 and terminate the episode. As slip probability grows, that bad outcome receives more probability weight, lowering Q-values for actions that pass close to the trap.

4. How does increasing the magnitude of the living penalty affect path length?
   living=+0.00: expected steps=6.6824
   living=-0.01: expected steps=6.6824
   living=-0.10: expected steps=6.3644
   living=-2.00: expected steps=5.0175

A more negative living penalty makes every extra normal step more costly, so the agent has stronger incentive to finish the episode quickly.

5. Does the agent reach terminal states faster?
Compare the expected-step values above. If they decrease as the penalty becomes more negative, the optimized policy is terminating sooner on average.

6. Under what conditions does the policy become more aggressive?
For living=-2.00, P(trap from start)=0.890136. An extreme living penalty can make quick termination preferable to accumulating many large negative step costs, even if that means accepting more trap risk.

7. Policy Evaluation vs Value Iteration
Policy Evaluation uses the Bellman expectation equation for a FIXED policy. Value Iteration uses the Bellman optimality equation with max over actions, so it simultaneously improves the value estimate and searches for the best policy.

8. Deterministic conversion
No new transition function is needed. Use the same stochastic code and set success_prob=1.0 and slip_prob=0.0. Then the intended action has probability 1 and both perpendicular outcomes have probability 0.
